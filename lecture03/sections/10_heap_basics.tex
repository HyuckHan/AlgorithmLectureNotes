\section{Part D. Heap과 Heapsort}
\begin{frame}{Heap은 Complete Binary Tree}
\begin{alertblock}{Index convention}이 단원에서는 heap array를 \textbf{1-based}로 표현한다.\end{alertblock}
\begin{itemize}\item 마지막 level을 제외하면 모두 가득 찬다.\item 마지막 level은 왼쪽부터 채운다.\item complete-tree shape 때문에 pointer 없이 compact array로 표현할 수 있다.\end{itemize}
\muted{배열 compactness는 heap-order property가 아니라 complete shape에서 나온다.}
\end{frame}
\begin{frame}{Max-Heap과 Min-Heap}
\begin{columns}[T]\column{.47\textwidth}\begin{block}{Max-Heap}$A[parent(i)]\ge A[i]$\\root가 최댓값\end{block}\column{.47\textwidth}\begin{block}{Min-Heap}$A[parent(i)]\le A[i]$\\root가 최솟값\end{block}\end{columns}
\vspace{5mm}\centering Heap property는 형제 사이의 순서를 말하지 않는다.
\end{frame}
\begin{frame}{1-based Heap Index 공식}
\[parent(i)=\left\lfloor\frac{i}{2}\right\rfloor,\qquad left(i)=2i,\qquad right(i)=2i+1\]
\begin{exampleblock}{index 3}parent=1, left=6, right=7\end{exampleblock}
\muted{참고: 0-based에서는 parent $\lfloor(i-1)/2\rfloor$, children $2i+1,2i+2$이지만 이 단원의 알고리즘에는 사용하지 않는다.}
\end{frame}

\begin{frame}{Heap 기초 Checkpoint}
배열 $[16,14,10,8,7,9,3,2,4,1]$에서 답하라.
\begin{enumerate}\item index 5의 parent와 children은?\item index 2 subtree의 값은?\item $A[2]=14$를 6으로 바꾸면 어디서 property가 깨지는가?\end{enumerate}
\begin{exampleblock}{답}1 parent: index 2, value 14; child: index 10, value 1만 존재. 2 values $14,8,7,2,4,1$. 3 index 2의 value 6은 index 4의 8과 index 5의 7 모두보다 작다.\end{exampleblock}
\end{frame}
