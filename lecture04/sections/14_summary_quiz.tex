\begin{frame}{Quiz 정답 I: Trace와 Complexity}
\small\begin{itemize}
\item $k=4$; $i=2$는 left rank 2, $i=4$는 pivot 12, $i=7$은 right rank $7-4=3$. Equal ranks 3–5에서 $i=4$의 답은 equal value다.
\item 목표 rank가 있는 한쪽만 재귀하므로 balanced recurrence는 $T(n/2)+\Theta(n)$이다.
\item worst: $T(n-1)+\Theta(n)=\Theta(n^2)$.
\item RandomizedSelect의 기대값은 현재 subarray에서 uniform하게 선택한 pivot index들의 random choices에 대한 평균이다.
\item Fixed version은 곧바로 $A[r]$를 사용한다. RandomizedSelect는 uniform $s$를 뽑아 $A[s]$와 $A[r]$를 swap한 뒤 같은 Lomuto를 호출한다.
\end{itemize}
\end{frame}
\begin{frame}{Quiz 정답 II: Group과 선택}
\small\begin{itemize}\setlength{\itemsep}{2pt}
\item $T(\lceil n/5\rceil)$은 medians의 median, $T(7n/10+O(1))$은 원본의 retained side upper bound, $\Theta(n)$은 grouping·partition이다.
\item Median 절반×group 수 $n/5$×group당 3개로 각 방향 $3n/10-O(1)$을 인증한다.
\item Size 3의 standard fraction 합은 1, size 5는 0.9다.
\item 후속 작업에 전체 순서가 필요하면 sort가 합리적이다.
\item 강의 $i=4$는 코드의 zero-based relative rank 3이다.
\end{itemize}
\begin{takeaway}Quickselect는 보통 빠르고, Median of Medians는 deterministic worst-case linear guarantee를 준다.\end{takeaway}
