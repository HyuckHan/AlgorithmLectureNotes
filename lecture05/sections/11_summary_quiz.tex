\begin{frame}{Quiz 정답 I}
\small\begin{itemize}
\item Fibonacci: State $F(i)$, Base $F(0)=0,F(1)=1$, Answer $F(n)$; 각 non-base transition은 한 번 평가된다.
\item Matrix State는 시작점부터 $(i,j)$까지의 최소합. $dp[3][3]=28$, $dp[4][4]=40$; 1-row는 left-to-right, time $\Theta(nm)$.
\item LCS Base는 row/column 0. match는 diagonal $+1$, mismatch는 up/left의 max.
\item 수학의 $X[i]$는 0-based 코드의 \texttt{X[i-1]}; 길이 4, 예: \texttt{BCBA}. LCS는 유일하지 않다.
\end{itemize}
\end{frame}
\begin{frame}{Quiz 정답 II와 흔한 오류}
\small\begin{itemize}
\item $bestEndingAt[i]$는 반드시 $i$에서 끝나는 값, $bestOverall$은 모든 끝점의 최댓값이다.
\item $ending[i]=\max(A[i],ending[i-1]+A[i])$; all-negative도 가장 큰 단일 원소다.
\item Fibonacci/Matrix/LCS/Kadane은 각각 $n$, $nm$, $mn$, $n$ state와 $\Theta(1)$ transition을 가진다.
\item optimal substructure는 최적해 구성, overlap은 같은 state 반복이다. Greedy에는 greedy-choice property가 추가로 필요하다.
\item 흔한 오류: 경계 초기화, min/max, answer 위치, sentinel, reconstruction 정보 손실.
\end{itemize}
\dptakeaway{State의 의미 → dependency → 평가 순서 → answer와 reconstruction 순서로 설계한다.}
