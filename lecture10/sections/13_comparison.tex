\begin{frame}{Worst-Case Complexity}
\begin{itemize}
\item Backtracking: subset \(O(2^n)\), permutation \(O(n!)\).
\item Branch-and-Bound: bound가 도움이 없으면 exponential tree 전체.
\item A*: 약한 heuristic과 큰 state space에서는 exponential time/memory 가능.
\end{itemize}
\begin{block}{구분할 metric}theoretical worst case, expanded-node count, bound/heuristic cost, peak frontier size.\end{block}
\end{frame}
\begin{frame}{Pruning은 Heuristic인가?}
\begin{itemize}
\item sound pruning은 correctness를 희생하지 않는 논리적 제거다.
\item heuristic은 탐색 순서나 optimistic estimate를 제공할 수 있다.
\item unsafe heuristic으로 prune하면 더 빨라질 수 있지만 exact algorithm이 아니다.
\end{itemize}
\end{frame}
